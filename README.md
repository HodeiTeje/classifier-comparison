# Classifier Comparison

A small machine learning project to learn the usage of basic ML libraries such as numpy or pandas by comparing classification algorithms using the Iris dataset. 

## Objectives

- Explore the Iris dataset.
- Train and compare KNN, Decision Tree and Naive Bayes.
- Evaluate models using appropriate metrics.
- Study the effect of feature scaling and model parameters.

## Technologies

- Python
- NumPy
- pandas
- scikit-learn
- Matplotlib

Initial setup. Model implementation and experiments are planned for the next usage.
